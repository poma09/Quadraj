# look — 내 옷으로 찾는 오늘의 코디

내 옷을 등록하고, 참고 코디와 오늘 입은 룩을 기록하는 첫 웹 프로젝트입니다.

## 실행하기

폴더에서 index.html을 브라우저로 열면 됩니다. 별도 설치는 필요 없습니다. 옷장과 코디 정보는 현재 브라우저의 localStorage에 저장되므로 이 브라우저에서만 보입니다.

## 파일 구조

~~~text
poma프로젝트1/
├── index.html          화면 구조 (HTML)
├── styles/style.css    색, 간격, 글꼴, 반응형 디자인 (CSS)
├── scripts/app.js      등록, 검색, 코디 저장 등 동작 (JavaScript)
└── README.md           실행 및 수정 안내
~~~

## 웹의 세 부분

- **HTML**: 화면에 어떤 제목, 버튼, 옷장 영역이 있는지 정합니다. 화면 내용은 index.html에서 고칩니다.
- **CSS**: 화면의 색, 글자 크기, 여백, 배치를 정합니다. 디자인은 styles/style.css에서 고칩니다. 맨 위 :root의 색상 변수를 바꾸면 주요 색을 조정할 수 있습니다.
- **JavaScript**: 버튼을 누르면 어떤 일이 일어날지 정합니다. 옷 등록, 코디 노트, 오늘 코디, 검색과 필터는 scripts/app.js에서 고칩니다.

## 현재 기능

- 옷 사진과 이름, 종류를 옷장에 기록
- 검색, 종류별 필터, 옷 삭제
- 참고 코디 사진을 저장하고 내 옷과 연결
- 오늘 입은 옷 조합을 기록해 오늘의 코디 카드에 표시

사진은 2MB 이하만 등록할 수 있습니다. 여러 기기에서 같은 데이터를 보려면 다음 단계에서 로그인, 서버와 데이터베이스, 이미지 저장소를 연결해야 합니다.
